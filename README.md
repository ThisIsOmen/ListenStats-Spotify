# Listen Stats

Android-приложение: читает, что играет (Spotify и Spotify Web Player в Chrome), считает прослушивания
по артистам, трекам и жанрам. Всё хранится локально на телефоне.

## Как получить APK без Android Studio
1. Создай аккаунт и пустой репозиторий на github.com.
2. Загрузи в него ВСЁ содержимое этой папки, включая скрытую папку `.github`.
3. Открой вкладку Actions -> Build APK -> дождись зелёной галочки (3-6 минут).
4. Открой выполненный запуск -> Artifacts -> ListenStats-apk, скачай и распакуй. Внутри app-debug.apk.
5. Установи APK на телефон (разреши установку из неизвестных источников).

Либо открой папку в Android Studio и нажми Build -> Build APK.

## Первый запуск
1. Открой приложение -> «Открыть» в баннере -> включи доступ к уведомлениям для Listen Stats.
2. Выбери для приложения режим батареи «Без ограничений».
3. Настройки (шестерёнка): ключи Spotify (developer.spotify.com, Client ID/Secret) и/или Last.fm для жанров.
   Без ключей жанры берутся из MusicBrainz.
